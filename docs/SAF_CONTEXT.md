# Still Afloat Project Context

## Project Overview
Still Afloat is a cruise-focused media and travel brand operated by Still Afloat LLC.

The project combines:
- Cruise vlog / YouTube channel
- Travel agency positioning
- Affiliate marketing
- Cruise planning resources
- Personality-driven cruise commentary

Core tone:
- Practical
- Experienced
- Tropical premium
- Funny without being cheesy
- Helpful without sounding corporate

Tagline:
> Cruise smarter. Laugh more. Stay Afloat.

## Design Philosophy
### Visual Direction
Blend:
- Jimmy Buffett
- Kenny Chesney
- Tropical premium resort
- Modern cruise aesthetic
- Caribbean blues and golds

Avoid:
- Cheap tiki bar feel
- Overly cartoonish cruise themes
- Generic travel-agency visuals

### Typography
Primary body:
- Baloo 2

Headings:
- Bree Serif

Accent script:
- Pacifico

### Color Palette
Primary Navy:
- #07183f

Ocean Blue:
- #0077b6

Seafoam Accent:
- #5dff9a

Sun Gold:
- #ffca4f

### Logo Treatment
Gradient script text should NOT use:
- -webkit-text-stroke

Preferred rendering method:
- layered navy text shadows
- gradient clipping
- geometric precision rendering

Reason:
webkit text stroke caused doubled/blurry rendering artifacts.
